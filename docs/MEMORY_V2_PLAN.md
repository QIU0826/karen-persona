# 记忆与拟人化重构方案（v0.5–v0.9，2026-10-20 定稿）

> 这份文档是**已批准的实施方案摘要**，用于把决定落到仓库里（避免只存在于对话中）。
> 详细文件级分解见各阶段 PR/CHANGELOG；本文记录**为什么这么做**与**验收标准**。

## 0. 立项前的实测事实

| 事实 | 证据 |
|---|---|
| 记忆金标稳定基线是 **16/20（80%）**，历史文档里的 17/20 是单次采样噪声 | 2026-10-20 用 HEAD 版 prompt 连跑 2 次均为 16/20 |
| **RAG 注入上限会伤召回** | 加上限后 16→14（连跑 3 次稳定），已回退 |
| **没有真向量检索** | `t2_episodes` 127 条，`semantic_embedding` 全为 NULL；`.env` 只有 DeepSeek Key |
| **用户事实层为空不是 bug** | 抽取链路实测正常（临时目录 6/6 入库）；真实会话 60 条用户消息里他从未说过自己的稳定事实——**问题是她不问** |
| 每轮对话 prompt p50 **2241** tokens、缓存命中 **46%** | `llm_usage` 81 次真实调用 |

## 1. 五层记忆（替代现在的 T0/T1/T2/T3 混用）

| 层 | 内容 | 进 prompt | 生命周期 |
|---|---|---|---|
| **Anchor 锚点** | 初见/表白/冲突/和好/承诺/秘密/共同经历 | 3–5 条，一行一条 | 永不衰减，可再巩固 |
| **Fact 事实** | 用户稳定信息 | 预算内（≤20 条/60 字） | 不衰减；冲突→质疑→确认 |
| **Daily 日记忆** | 每天一条摘要 + 未完成话题 | 最近 3 天 | 180 天后折进周汇总 |
| **Episode 情节** | 单轮/片段对话（现有 T2） | 检索 top-k | 艾宾浩斯 + 热度 |
| **State 状态** | 亲密度/情绪/能量/忙碌/张力 | 5 个数值（~30 token） | 实时 |

关键决定：
- **T1 不再注入「最近状态弧」文本**（与最近消息冗余），只留数值状态卡。
- **T3 取消「40 条一刀切」**，改日摘要 + 周汇总；长期摘要的作用是叙事连续性，不替代事实。
- **遗忘分层**：事实不衰减、锚点免疫、情节衰减——符合真人（事实记得牢，细节会淡）。

## 2. 本地向量（替换「关键词 + 每轮 LLM 重排」）

- 服务：`services/embed/`（Python + `uv`，独立进程，HTTP 调用，不进 npm 依赖）。
- 模型：**Qwen3-Embedding-0.6B**（支持 MRL 截断到 768，零 schema 迁移）优先；
  **bge-m3**（1024 维，需重建 `t2_vec`）备选。P1 第一天用 40 条金标 spike 决定。
- 检索流水线：`kNN(20) + BM25(20) → RRF → 本地 rerank → 热度/新近/显著度重排 → 预算打包`。
- 去掉每轮 DeepSeek 重排（省 ~664ms、¥0.00025/轮）；服务不可用自动降级 ngram。
- 模型目录统一 `KAREN_MODELS_DIR`（默认 `~/Library/Application Support/karen/models`），
  `npm run models:status|list|purge` 管理，仓库内不落模型。

## 3. 事实的质疑与冲突（真人对离谱信息会怀疑）

```
抽取 → 接地校验 → status=pending
  ├─ 与已 confirmed 冲突 → 下轮自然求证一次（"你说在成都？我记得你之前说杭州诶"）
  ├─ 确认 → confirmed + 写 user_fact_history
  └─ 否认/含糊 → disputed（不再注入）
```
- 每条事实只质疑一次（`challenged_at`），`/fact off` 可关。
- **配套产品动作**：认识初期她应主动问 1–2 个问题（做什么工作/在哪个城市），
  否则事实层永远没原料——这是本次实测暴露的真问题。

## 4. 拟人化交互（v0.6）

- **节奏模拟器** `src/bridge/pacing.ts`：readDelay（0.6–8s）+ burst（1–4 条，按语义断句）
  + hesitation + 忙时 defer；人设新增 `typingWpm/burstiness/hesitation`。
- **消息意图** `src/bridge/message-intent.ts`：typo_recall(4%) / regret_recall(2%) /
  rewrite(3%) / hesitate；全部沿用现有 15s+5s 撤回护栏。
- **表情包持续收集** `src/data/sticker-library.ts`：入站图片/表情包 → hash 去重 → 视觉打标
  → 热度排序使用；`/sticker on|off|list|purge|add`；库容 500、单文件 ≤2MB。

## 5. 媒体 / 主动 / 关系 / 语音

- **v0.7 ComfyUI 本地生图**（约 20% 照片，80% 图库；程序在 `vendor/`、模型在 `KAREN_MODELS_DIR`、
  生成物 `data/generated/` 自动清 30 天）。
- **v0.8 意图式主动**（每日由头计划 + 抑制 + 按回复率校准）、**五维关系**（intimacy/trust/tension/
  reciprocity/dependency + 阶段机）、**反思循环演化**（日/周/月 + 可回滚）。
- **v0.9 语音**：IndexTTS 零样本克隆（需 10–20 秒参考音），失败回退 `say`。

## 6. 验收标准（每阶段门禁）

| 阶段 | 指标 |
|---|---|
| v0.5 | 金标 40 条 ≥36；事实≥10 条且 0 错记；prompt p50 ≤1900；检索 p95 ≤250ms；"三天前的事"抽检 ≥16/20 |
| v0.6 | 盲评"像人" ≥70%；三种状态时长差 ≥30%；4 类撤回各 ≥1 次；表情包库 ≥100 |
| v0.7 | 单张生图 ≤12s、失败率 <10%、磁盘占用可见可清 |
| v0.8 | 主动消息回复率提升、五维可解释 |
| v0.9 | 语音盲评"像人" ≥60% |

## 7. 开关与回退

- `KAREN_MEMORY_V2`、`KAREN_RETRIEVAL_V2`、`KAREN_PACING_V2`、`KAREN_STICKER_COLLECT`、
  `embedding_provider(local|none|api)`。
- 迁移只加表/加列，不删不改旧字段 → 关掉开关即回到 v0.4.1 行为，数据保留。

## 8. 数据主权（新表必须同步覆盖）

- `/export` 增加 facts/anchors/digests/stickers 索引；`/forget` 级联删锚点与日记忆；
  `/about` 说明本地模型在本机推理不外发；`/forget --all` 二次确认清空记忆类表。
- 保留期：生成图 30 天、日记忆 180 天、贴纸库 500 张。

## 9. 进度（2026-10-20）

### v0.5 已落地（详见 CHANGELOG v0.5.0）

- schema v4（锚点/日记忆/周汇总/调度记录 + 扩展列），真实库迁移已验证；
- 本地向量服务 + Node 客户端，127/127 条历史记忆重嵌入，检索 p95 从 ~664ms 降到 <100ms；
- 本地向量启用时**默认关闭每轮 LLM 重排**：金标 live 16/20 → 17–18/20；
- 锚点记忆（规则显著度）+ 日记忆/周汇总调度（幂等 + 开机补跑）+ 状态卡；
- 事实状态机（pending/confirmed/disputed）+ 冲突质疑 + `/fact` 命令。

### v0.6 已落地（详见 CHANGELOG v0.6.0）

- 她主动了解你：认识初期问工作/城市/宠物/名字/计划，问过的落库不重复（解决"事实层没原料"）；
- 打字节奏模拟器：人设 × 情绪 × 深夜 × 忙碌 → readDelay / 每字耗时 / 条间间隔 / 犹豫；
- 消息意图族：打错字 / 说重了 / 重发更短的 / 犹豫，共享撤回护栏；
- 表情包持续收集：入站图片自动入库存盘、去重、库容淘汰、可一键清空；
  **采集默认关（KAREN_STICKER_COLLECT=on 才开），出站使用默认关（KAREN_STICKER_USE=on 才开）**。

### v0.8 已落地（详见 CHANGELOG v0.8.0）

- **五维关系接进主流程**：`persona-state` 持久化五维（老状态按亲密度补起点）；每轮关系事件后演化

### v0.8.4 已落地：锚点二次筛选

- 每天一次（心跳里，幂等）：挑出「边界候选」（显著度 0.45–0.75、当天、未进锚点，最多 12 条），
  交 LLM 判断值不值得长期记住 → 写入 `memory_anchors`（带更准的 kind 与一句话摘要）。
- 成本护栏：候选 <2 跳过、每天最多一次、记账 `llm_usage.kind=anchor_refine`。
- 真实库实测：12 条候选全判「不值得记」（当天确实是闲聊），0 误建，2.0s 一次调用。
- 过程中修掉两个真 bug：`t2_episodes.created_at` 是 TEXT 不能当毫秒比；
  「全部拒绝」被误报为解析失败。
