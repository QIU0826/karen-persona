# 对话真人化巡检（2026-10-22）

## 已启动的自动任务

- 调度：每 **5 分钟**一次（当前会话的 reminder；ID 在 schedule 列表可见）
- 脚本：`npm run chat:audit -- --limit 40`
- 输入：`data/<persona>-session.json` 最近 40 条消息
- 输出：`data/realism-audit/latest.json` / `latest.md`
- 无新消息自动跳过，不重复消耗 API

## 首轮结果（真实会话，2026-10-22 21:27）

- 真人感：**8/10**
- 问题：
  - 图片和文字同时到达时，只接了图，漏了“吃了呀”
  - 用户夸图，她误以为在夸自己发的表情包
  - 表情包解读强行套自己（“这是在说我下班吗”）
  - 偶发完整句/解释腔
- 建议：
  - 先确认图内容再评价，别把用户发的图当成自己拍的
  - 图和文字至少都接一下
  - 表情包不要强行关联自己，先问或只做搞笑反应
  - 保留短句、停顿、反问

## 已知限制

- 巡检是 LLM 判断，不是绝对标准；目前只写报告，不自动改 prompt。
- 表情包 AI 备注（`sticker_library.note`）**没有注入聊天上下文**；所以她能按标签挑选，却不能稳定解释某张表情含义。
- 入站图片当前轮最多带 2 张原图直接看；其余靠后台文字描述。
