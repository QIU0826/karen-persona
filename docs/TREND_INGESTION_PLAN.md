# 热梗 / QQ 动态 / 手机抓取：可行路线（2026-10-22）

## 现状

- **表情包**：内置 11 张只有 `happy/cute/tired` 等标签；收藏表情有 AI `note + scene_tags + emotion`，
  但这些 note **没有进入聊天 prompt**。所以她“会挑”，不一定“懂”。
- **图片**：入站图会下载成 data URL，当前轮最多 2 张直接附给多模态模型；后台再生成文字描述写回历史。
  不是“先全转文字再给她看”，而是当前轮直接看原图。
- **回复表情包**：没有强制；收到表情只提高回贴纸概率（默认 55%），可以只回文字或不回。
- **热梗**：没有实时热榜/搜索接入，只有模型训练知识，无法保证“今天”的梗。
- **QQ 动态**：当前只有 OneBot 消息，没有 Qzone 发动态/点赞/评论能力。
- **手机/抖音**：没有接入。

## 推荐路线（按稳定性）

### A. 热榜 API + 链接 ingest（推荐）

1. 每 30–60 分钟抓一次公开热榜（百度/微博/知乎/抖音热榜），只取标题+热度，不抓评论；
2. 用 LLM 压成 10–20 条“今天大家在玩什么梗”注入记忆/对话上下文；
3. 用户分享抖音/QQ 链接给 bot → `yt-dlp` 取元数据/音频（不登录），ASR + 画面抽帧/OCR，压成一句摘要；
4. QQ 动态可做成“她偶尔发一条”的离线草稿，人工确认后再发；不做自动点赞/评论。

优点：稳定、无需手机、可审计；风险：第三方热榜 API 可能限流，抖音链接解析需定期维护。

### B. 手机辅助（可选，不建议做核心）

- Android 无障碍服务/Tasker/Auto.js/ADB 监听分享或截屏 → 传到 Mac；
- 能拿到手机里看到的视频/文案，但：要常驻、耗电、隐私面大、系统限制多、可能违反平台 ToS。
- 适合“只抓自己愿意分享的内容”，不适合无人值守抓全站。

### C. 抖音官方/非官方 API

- 官方开放平台需要企业资质；个人 bot 不可用。
- 非官方签名接口（X-Bogus/a_bogus 等）频繁变化，账号有风控风险；不建议作为长期方案。

### D. 人工投喂（最稳的兜底）

- 你看到好梗/好视频，转发链接或截图给 bot；bot 走 A 的解析/摘要；
- 成本最低，内容质量最高，也不会碰平台风控。

## 建议的落地顺序

1. 先做热榜 API + 每日 20 条“梗摘要”注入；
2. 再做链接 ingest（`yt-dlp` + ASR + 抽帧）；
3. 最后才评估手机辅助；Qzone 先只做人工确认草稿。
