# 语音质量：为什么听起来像 AI，以及改了什么（v0.4.1）

> 反馈原文：「语音太 AI 了，没有真人感」。
> 本文只写能在本机复现的事实；**「像不像真人」最终只能靠耳朵判断**，所以我生成了样音让你自己比。

## 1. 为什么像 AI（三个原因，按影响排序）

| # | 原因 | 事实依据 |
|---|---|---|
| 1 | **音色本身老** | 用的是 macOS `say` 的 `Tingting`（2008 年前后的中文女声，共振峰合成）。本机 184 个语音里，中文只有 Tingting / Meijia(zh_TW) / Sinji(zh_HK) 和几个「Eddy/Flo/Sandy」旁白音色，**没有任何 Premium/Enhanced/Siri 中文语音**（`say -v '?'` 实测，无 premium/enhanced 字样） |
| 2 | **语调是一条直线** | 旧实现固定语速 185、全程一个音高、只在标点处由引擎默认停顿 —— 这就是「朗读腔」 |
| 3 | **SILK 窄带压缩** | QQ 语音走 SILK，本身有损失（实测同一句 4.8s 音频编解码后仍有 ~4.8s，但高频被切） |

## 2. 这次做了什么（可量化）

`say` 支持内嵌语音命令，我逐条实测有效（macOS 26 / M5 Pro）：

| 命令 | 实测效果 | 证据 |
|---|---|---|
| `[[slnc 600]]` | 插入 600ms 静音 | 同一句时长 3.89s → 4.51s（+0.62s） |
| `[[pbas +18]]` | 提高基频 | 自相关测基频中位数 212.4Hz → 358.2Hz |
| `[[rate 120]]` / `[[rate 260]]` | 分句变速 | 同一句 4.63s / 3.13s（基准 180 时 4.23s） |

基于这三条，新增 `src/ai/tts-style.ts`（28 条单测）：

1. **按情绪/作息选风格**：`lively`（开心，快 5%、+3 音高）、`natural`、`soft`（低落，慢 6%、-2）、`tired`（23:00–06:00，慢 10%、-3）。
2. **句内语调轮廓**：按标点分句，每个分句单独下发 `[[pbas]]` + `[[rate]]`——起句略慢、中间正常、收尾略慢；陈述句句末降调，**问句句末升调**；分句之间插入 140–520ms 停顿（总停顿封顶 700ms）。
3. **偶尔加语气词**（默认 12% 概率）：`嗯…` / `那个…` / `诶，` / `唔…`，只加在 6–40 字、以句末标点结尾的句子上；已以语气词开头则不加。**只影响念出来的音频，不改消息原文。**
4. **音色可配**：`voice_tts_voice`（默认 Tingting，可换 Meijia/Sinji/装了的高质量语音）、`voice_tts_rate`（默认 180）、`voice_style_enabled`、`voice_filler_probability`。

真实链路实测（`synthesizeSpeech` → SILK，本机）：

| 风格 | 语速 | 音高 | 停顿合计 | 音频时长 | SILK 体积 | 合成耗时 |
|---|---|---|---|---|---|---|
| natural（下午） | 185 | 0 | 431ms | 4.62s | 19,614B | 610ms |
| lively（开心） | 198 | +3 | 333ms | 4.38s | 18,991B | 566ms |
| tired（凌晨） | 167 | -3 | 542ms | 4.82s | 20,059B | 561ms |

## 3. 试听与换音色

```bash
node node_modules/tsx/dist/cli.mjs scripts/voice-sample.ts
# 产物在 data/voice-samples/（不进仓库），附 README.md 说明每个文件是什么
```

每组三档：`-0-旧版`（固定语速无起伏）、`-1-<风格>`（新版）、`-2-<风格>-silk往返`（≈ QQ 里真正听到的音质）。
换音色只需在 `config.yaml` 里加一行 `voice_tts_voice: "Meijia"`。

## 4. 天花板在哪：`say` 就是到不了「真人」

上面这些能让它**不那么像在念稿**，但音色本身还是 2008 年的合成声。要真正接近真人，必须换神经 TTS。这次我实测了三条路：

| 方案 | 需要什么 | 实测结论 |
|---|---|---|
| **微软 Edge 神经语音**（`zh-CN-XiaoxiaoNeural` 等，免费无 Key） | 无 | ❌ **不可用**：`voices/list` 接口 200（说明令牌算法正确，能列出含 Xiaoxiao/Xiaoyi 的 12 个中文神经音色），但合成用的 WebSocket 握手一律 **403**（试了 4 种参数组合、4 个 `Sec-MS-GEC-Version`）。微软在 2026-10 已收紧，非官方通道不再可用 |
| **Azure Speech / 火山引擎 / 阿里云 TTS** | 账号 + Key（按字符计费） | 未接。技术上就是把 `synthesizeSpeech` 的「合成」一步换成一个 HTTP 调用，改动约 100 行；需要你提供 Key |
| **本地神经 TTS**（sherpa-onnx / piper / kokoro 的中文模型） | 下载 60–300MB 模型 + 一个原生依赖 | 未接。离线、免费、无 Key，但会增加安装体积与首次启动时间 |

**我的建议**：先用现在的版本听一下样音。如果你觉得「不那么像念稿了」但音色还是假，那就是该上神经 TTS 了——最省事的是云厂商 TTS（你给 Key，我接），其次是本地模型（不用 Key，但安装变重）。

## 5. 局限（别夸大）

- **我无法判断「像不像真人」**：我只能测基频、停顿、时长这些客观量，听感需要你确认。
- 语气词、停顿、音高都是**规则驱动**，不是真正的韵律模型；同一风格多次生成，句内起伏模式会重复。
- SILK 编码不可绕开（QQ 语音消息格式），高频损失是固定的。
- `[[pbas]]` 在部分系统音色上可能被忽略（本机 Tingting 实测有效，其它音色未逐一验证）。
