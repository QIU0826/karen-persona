# 本地图片库（她主动分享的「随手拍」兜底）

- 用途：未配置 `UNSPLASH_ACCESS_KEY`（或 Unsplash 搜索失败）时，她仍能主动发一张本地图片。
- 来源：[Lorem Picsum](https://picsum.photos)（`https://picsum.photos/seed/<seed>/800/600`），
  图片素材来自 [Unsplash](https://unsplash.com)，适用 [Unsplash License](https://unsplash.com/license)
  （可免费商用、无需署名；本文件作为来源记录）。
- 尺寸：800×600 JPEG，单张 20–110KB；共 7 张（去重后）。
- 每张图在 `src/impulse/photo-library.ts` 中有内容标签与配文；替换图片时请同步更新标签/配文。
- 商用前请自行复核图源许可；若替换为第三方素材，更新本文件并确认授权。
