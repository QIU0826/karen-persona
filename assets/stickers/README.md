# 本地贴纸资源

当前内置 11 个 PNG 表情图，用于「她主动发一个表情」的场景（OneBot CQ image base64 发送）。

## 来源与许可

- 图形来自 [Twitter Twemoji](https://github.com/twitter/twemoji)（72×72 PNG，`assets/72x72`）。
- 许可：[CC-BY 4.0](https://creativecommons.org/licenses/by/4.0/)。
- 文件名即 emoji 的 Unicode 码点（如 `1f63a.png` = 😺）。

## 替换/扩展

- 保持文件名与 `src/impulse/stickers.ts` 的目录项一致即可替换为其他人设贴纸（自制/授权素材）。
- 若替换为第三方素材，请确认许可证并更新本文件；商用前必须逐项核对授权。
- 资源缺失时贴纸功能会静默降级，不影响文字回复。
